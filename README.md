# Бот приёма заказов на мебельные фасады

Telegram-бот на Python (aiogram 3). Клиент отвечает на четыре вопроса, заказ записывается в Excel, а владельцу приходит уведомление в Telegram.

Это демо-проект: тексты и сценарий легко заменить под любой бизнес (мебель, ремонт, салон, доставка).

## Что умеет

- Оформление заказа по шагам: что нужно, размер, телефон, комментарий
- Проверка номера телефона и понятное сообщение, если номер неверный
- Запись каждого заказа в `orders.xlsx` с датой, именем и @username клиента
- Уведомление владельцу в Telegram о новом заказе
- Раздел «Частые вопросы» и кнопка отмены на любом шаге
- Автотесты, которые проверяют весь диалог без обращения к Telegram

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # впишите BOT_TOKEN и ADMIN_CHAT_ID
python bot.py
```

Токен бота выдаёт @BotFather. Свой ADMIN_CHAT_ID можно узнать у @userinfobot.

## Тесты

```bash
pytest -q
```

## Структура

| Файл | Назначение |
| --- | --- |
| `bot.py` | сценарий диалога, кнопки, уведомление владельцу |
| `storage.py` | проверка телефона и запись заказов в Excel |
| `tests/test_bot.py` | тесты телефона, Excel и полного диалога |

## Что можно доработать под заказчика

- Выгрузка заказов в Google Таблицу вместо Excel
- Каталог с фото и ценами, выбор товара кнопками
- Автоответ вне рабочих часов
- Запуск на сервере (systemd или Docker) и хранение состояния в Redis
